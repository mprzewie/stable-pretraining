# directional_cuda.py (coupling_cuda/apply_cuda) additionally JIT-compiles fused kernels on first
# import (torch.utils.cpp_extension -> nvcc), so on the machine that runs it you also need:
#   * a CUDA GPU,
#   * the CUDA toolkit (nvcc) matching your torch build's CUDA version,
#   * a host C++ compiler (Linux: gcc/g++; Windows: MSVC Build Tools).
# Set the target arch before running, e.g.:
#   Linux  :  export TORCH_CUDA_ARCH_LIST=9.0      # H100 (8.0 A100, 8.9 Ada, 12.0 Blackwell, ...)
#   Windows:  set   TORCH_CUDA_ARCH_LIST=12.0      # RTX 50-series
#
# RTX 50-series (Blackwell) needs a CUDA 12.8+ torch wheel:
#   pip install torch --index-url https://download.pytorch.org/whl/cu128
